# Image Assets

## Placeholders

Replace the following placeholder files with actual images before deploying:

- `default-banner.jpg` — Site-wide fallback banner (recommended: 1200x400px)
- `avatar.jpg` — Personal profile photo (recommended: 200x200px)
- `posts/` — Post banner images (naming: `YYYY-MM-DD-post-title.jpg`)
- `projects/` — Project banner images (naming: `YYYY-MM-DD-project-name.jpg`)

## SVG Placeholders

While waiting for real images, SVG placeholders are provided:
- `default-banner.jpg` → rename/replace with `default-banner.jpg`
- `avatar.svg` → rename/replace with `avatar.jpg`
